# partyOS removed-packages list
# ------------------------------------------------------------------------------
# partyOS is built from the stock Arch *installer* ISO (releng) profile, which is
# a kitchen-sink recovery/install environment. This file lists packages stripped
# from the image because partyOS netboots straight to an XFCE desktop and never
# installs Arch, recovers disks, or runs as a VM guest.
#
# DOUBLES AS the undo list: `pacman -S <name>` (from a LAN Arch mirror) brings any back.
#
# phases/25-strip.sh reads this file and `pacman -Rns` each (best-effort: a
# pkg still required by a keeper is left in place + logged). Lines starting with
# '#' and blank lines are ignored.
# ------------------------------------------------------------------------------
