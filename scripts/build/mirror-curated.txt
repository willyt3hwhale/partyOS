# mirror-curated.txt - the curated package list for the LAN mirror (server/lanmirror).
# Players install these offline with "pacman -S <name>" from the [partyos] repo.
#
# Selection (2026-09-23):
# 1. Rank by pkgstats.archlinux.de popularity, and select for a LAN party on the XFCE client.
# 2. Use only packages in the pinned 2025/09/01 snapshot (core and extra, no multilib).
# 3. Do not include packages in the client image, packages already in the mirror,
#    or games and apps in the store catalog (server/games/catalog.v2.json).
# The new packages, dependencies included, are about 5.3 GB (compressed).
#
# Add all of the list (blank lines and "#" lines are not packages):
#   bash scripts/build/mirror-pkgs.sh $(grep -v '^#' scripts/build/mirror-curated.txt)
